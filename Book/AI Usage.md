# Notes on content generation using AI:

I have and will continue to use AI to generate content for, and assist in the maintenance of this work. This is likely a red flag for a lot of you so please let me explain my workflow and the use of this technology.


All written content is directly written by myself or a fellow (human) faculty member. This can come from directly writing page content, transcriptions of lectures, or written information from slides. Once that content is in a .md file I have a process that I work through with Claude. 

+ I use the following process:
	    1. I or a co-author generates a .md file with unformatted content and notes.
		2.  A set of custom Claude skills in a co work project formats that information using a page template that I have created.
	    3. I will provide media links, "HTML Widgets," or Excalidraw drawings which will be check by Claude and included.
	    4. Claude will then look for backlinks, and future backlinks then format and add those.
	    5. All content is then flagged as ready for human review/ final editing and publishing.
	    6. Claude will periodically look through the vault and identify broken links, missing materials, and keep a To-do- list updated at all times.

TLDR; The first words on any page come from a person, AI is the editor and maintainer, and the final read through and publication comes from me. I am also a human and I may make mistakes, miss things, and occasionally stray from the path that the AI overlord has set out. For that reason the blame for any mistakes lies with me.
